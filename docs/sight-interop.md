# Optional Sight visual signal interop

Contract source: live-latent-lab-sight-public revision d140d38, src/core/sight_snapshot_v1.h, src/core/sight_motion_v1.h, src/core/sight_snapshot_export.hpp, src/core/hand_signals.cpp, src/core/tracking_discovery.hpp, src/tracking-signal-receiver.cpp and src/u2net-filter.cpp. The two caller-owned v1 wire headers are copied unchanged under src/interop/sight. No implementation linkage.

- Motion (source ID 7): resolve a U2Net filter using parent/filter UUID, verify enabled/attached state, read sight_motion_read_v1 with max_age_ms=500, and accept only available v1 snapshots with exact size, nonzero sequence, matching nonzero source dimensions and finite energy in [0,1]. Energy means whole-frame luma delta, not velocity.
- Hand X/Y (8/9) and pinch closeness (10): use a temporary private sight_tracking_receiver_filter to call sight_tracking_list_v1 and sight_tracking_read_v1, without attaching/rendering the receiver. Require exactly one enabled unambiguous hand channel in the inventory, available v1 snapshot of matching kind, sequence and bounded counts, and a finite wrist coordinate/confidence or valid pinch value. X/Y use normalized wrist coordinates of the first reported hand, clamped to [0,1]. Pinch is already normalized closeness in the producer implementation (1=pinched, 0=open), despite the older distance comment in tasks_tracker.hpp. No handedness identity guarantee.
- The shared Sound/Sight polling worker runs outside audio callbacks. Snapshots carry read-start timestamps, expire locally after 500 ms and drive a 10 ms ramp. Missing/invalid/stale inputs contribute zero. The producer also enforces max_age_ms=500 for Sight. Serial polling can delay other subscriptions; temporary reader creation and inventory discovery have not been profiled for live OBS workloads. Worker shutdown still depends on returning producer calls.
- Both native and LADSPA expose the new sources for each of four routes. Saved Sound keys are unchanged. Sight motion uses UUID pairs; tracking follows Sight's named channel protocol. Missing saved selections are retained.

Verification uses fixtures registered in actual libobs with the producer's procedure signatures and caller-owned ABI structures, not actual models. Native stereo capture verifies X/Y, pinch, ambiguous channel rejection, wrong ABI and absent detection. LADSPA SDK amplifier verifies motion energy, invalid dimensions, tracking, selected-channel picker and detached producer fallback. Existing Sound integration and no-producer audio tests remain in the suite. Installed OBS frontend, actual Sight producers, GPU lifecycle and CPU overhead remain unqualified.
