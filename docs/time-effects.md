# Native time effects

The reusable FractionalDelay in src/framework/dsp/time_effect.hpp prepares a channel-major circular buffer sized to two seconds plus two samples per channel, using linear interpolation between neighboring taps. TimeEffect owns that buffer and the shared modulation matrix, mixer, parameter ramps and linked oscillator clock. At stereo 48 kHz the delay buffer occupies 768,016 bytes; storage scales with channels and sample rate and is allocated on reset/control path only. Feedback is bounded to +/-0.95 and internal delay writes to +/-128 to prevent unbounded invalid signals; this is not an output safety limiter. Feedback damping is a one-pole smoothing coefficient (0 bypass, 0.99 maximum), not a sample-rate-independent cutoff. Negative feedback alternates polarity. Feedback routing crosses adjacent channel pairs in ping-pong mode, not all channels indiscriminately.

Echo uses a fixed fractional tap, chorus averages two moving taps in quadrature, flanger uses one moving tap plus feedback, vibrato uses one moving tap without feedback. Chorus has no feedback. Delay center/oscillator excursion are constrained to the mode-specific short-delay limit. Stereo spread offsets adjacent channel oscillators by up to half a cycle. Pure vibrato requires full wet. Wet/dry intentionally mixes delayed and undelayed samples; there is no dry alignment for creative delay effects. Mode changes logically clear history in constant time (without zeroing the backing buffer); continuous parameters ramp over 10 ms. Time changes can pitch-shift, and switching modes is not crossfaded. No tempo sync or dedicated sidechain.

Core tests verify 48-sample echo and ping-pong impulse sequences, fractional 1.5-sample interpolation, negative feedback, damping, maximum 2-second delay and wrap at 44.1/96/192 kHz, modulated delay block partition independence, stereo phase differences, finite output, bypass and external mix routing. Actual libobs stereo capture exercises all five effect modes, half-period cancellation, full-period addition, feedback gain, cross-channel ping-pong and Sound confidence modulation/fallback with a contract fixture. Measured 1 kHz echo at 1 ms and 0.5 feedback gives 0.565685 RMS; the ping-pong pair gives 0.452548/0.339411. No live neural inference, installed GUI or CPU-budget qualification.

The OBS adapter prepares format-dependent engine storage and external subscriptions on the control path, then adopts latest settings at audio block boundaries without a processing mutex. Same-mode edits preserve DSP history; explicit mode/topology changes retain their documented reset behavior. A downstream libobs regression compares two freshly created filters on identical bursts and silence, with concurrent changes to mode-inactive controls on one, and checks both channels sample by sample.

The [Linux callback audit](realtime-profiling.md) includes echo with concurrent settings edits and allocation instrumentation. The [native CI matrix](ci.md) runs the required numerical and OBS integration tests on all eight targets; neither establishes exhaustive mode coverage or a physical-device deadline guarantee.
