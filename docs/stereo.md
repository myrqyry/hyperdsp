# Stereo imaging

Standalone hyperdsp_stereo_filter and graph native:hyperdsp_stereo_filter:1 share Stereo. Mid=(L+R)/2 and Side=(L-R)/2; independent gains in -24 to +24 dB and width 0–2 multiply these components before L=Mid+Side and R=Mid-Side. Balance attenuates the opposite channel linearly (-1 left, +1 right); it does not pan a mono signal or apply constant-power compensation. Common input/output trim and linear wet/dry use the existing mix engine. Continuous changes ramp over 10 ms. Mode bypass returns unmodified audio. Width-only changes preserve the summed mono component; mid gain, balance and other controls can alter it. No decorrelation, delay, channel synthesis, peak protection or fixed sample-buffer latency. Intended for exactly two channels; other standalone layouts pass through untouched and graph preparation rejects them. All seven numeric parameters can be bound to graph macros. No dedicated standalone modulation routes yet.

## Mono compatibility diagnostics

The standalone filter estimates exponentially weighted L², R² and L×R at its output with 250 ms time constant. Correlation is normalized cross-power in [-1,1] (not mean-subtracted Pearson correlation), undefined for a silent channel. Mono-fold loss is 10 log10(power of (L+R)/2 / mean channel power), with -120 dB floor; side fraction is side energy / (mid+side energy). Silent or stale data is unavailable. Output diagnostics also measure the unprocessed stereo signal while the filter is in its internal bypass mode. The versioned hyperdsp_stereo_status_v1 procedure returns available, correlation_valid, correlation, mono_loss_db, side_fraction; OBS properties have a manual Refresh diagnostics button. Publication uses lock-free atomic values and a sequence check; reader takes no processing mutex. Values older than 500 ms or from a disabled filter are unavailable. Explicit settings edits reset the averaging state; the display needs time to settle. The applied graph Monitor now has a separate live stereo vectorscope and short-window metrics; standalone diagnostics remain manual refresh. Correlation and fold-down loss are descriptive signal metrics, not perceptual guarantees.

## Evidence

Core tests cover neutral identity, mono sum, width 2, M/S gains, balance, dry blend, unsupported layout bypass, graph compatibility/zero fixed latency and exact sample partition agreement on a ramped update. Diagnostics distinguish +1/-1 correlation, cancellation floor, single-channel -3.0103 dB fold loss and undefined correlation. Actual libobs downstream probe measures width 2 on L=.4/R=-.2 as .7/-.5 with correlation -1 and fold loss -15.682 dB; width 0 yields .1/.1 with settled correlation .999994 and negligible fold loss. The graph macro reproduces both outputs. Test verifies stale/disabled diagnostic rejection; registry and CLI tests cover stereo-only compatibility and parameter parity. No physical listening or callback performance benchmark.
