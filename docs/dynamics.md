# Native dynamics

The DSP engine lives in src/framework/dsp/dynamics.hpp; the OBS adapter is src/dynamics-filter.cpp. New effect adapters can reuse src/framework/obs/route_properties.hpp, which provides consistent four-route metadata, saved settings, visibility and optional external connections. Existing native and LADSPA saved keys remain unchanged.

The detector is max absolute channel sample with instantaneous rise and exponential decay; a linked gain envelope operates in dB. Static compression above threshold uses (1/R−1)*(level−threshold); downward expansion below threshold uses (R−1)*(level−threshold), bounded by range. Quadratic soft knees meet the straight segments continuously. Attack/release are one-pole time constants, not guaranteed time-to-target. The gate opens at threshold, retains its state within the hysteresis band, holds below that band, then closes toward the range. Limiter gain reduction attacks immediately; a final wet-branch sample clamp includes makeup gain, not dry blend or output trim. No lookahead, true-peak, oversampling, external sidechain, RMS detector or guarantee against bypass during a control update. Peak detector and gain release are distinct smoothing stages.

Four routes sum signed contributions to threshold (dB), ratio, makeup (dB), range (dB), wet/dry and output amplitude. The first four are bounded in effect units; mix and amplitude use normalized amounts. All optional neural inputs use the existing worker/snapshot contract. Continuous base controls ramp over 10 ms except timing and gate hold/hysteresis; mode changes reset detector/gain state rather than crossfade.

Verification: static DC compressor at −20 dB threshold, 4:1 ratio gives 0.177828 from 1.0; expansion at −20 dB threshold, 2:1 gives approximately 0.001 from 0.01; 60 dB gate attenuation gives 0.00001 from 0.01. Gate hold/hysteresis measured separately. Limiter handles isolated impulses and makeup at 44.1/48/96 kHz with unity output trim and full wet. Actual libobs stereo tone capture checks all modes, stereo gain ratios, bypass and Sound confidence fixture ducking/fallback. This is not a live neural-model, visual frontend or CPU-budget qualification.
