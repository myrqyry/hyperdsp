# Native space effects

The reusable Space engine in src/framework/dsp/space.hpp supports a phaser and algorithmic reverb. FractionalDelay is now in its own header, with a bounded prepare_samples() method for shorter delay networks; the existing TimeEffect API and behavior are retained.

Phaser cascades 2–12 first-order all-pass sections. The bilinear coefficient is (tan(pi*f/fs)-1)/(tan(pi*f/fs)+1), with the sweep limited below Nyquist. Each channel has independent state, and odd channels can have an offset LFO phase. The signed feedback is bounded to +/-0.85. The dry/wet blend creates the phase-cancellation notches; the static fully wet cascade at zero feedback retains magnitude. The 2-stage 1 kHz configuration at 50% wet cancels a 1 kHz tone. Audio storage is allocated on the control path only.

Reverb uses a four-delay network per channel pair. Base delays are 29.7, 37.1, 41.1 and 43.7 ms, scaled by room size (0.5–1.9), rounded to samples. Feedback uses a normalized 4x4 Hadamard matrix, one-pole damping and per-line gain 10^(-3*delay_seconds/decay_seconds). This is a nominal RT60 parameterization, not a measured room RT60. Input pre-delay is up to 200 ms and each stereo input has an independent Schroeder all-pass diffuser. Wet output is a mid/side projection with adjustable width. Adjacent channel pairs are separate networks; unpaired mono uses a common projection. Delays are allocated to the actual rate and channel count, with capacity for maximum room size; no allocations during the DSP process call. The network write is bounded for invalid/extreme inputs, not a safety limiter.

All four modulation routes are available. Continuous base controls ramp over 10 ms; mode or stage changes reset state and size edits can cause integer-tap jumps. Delay gains are cached while decay/size stay unchanged; modulation can cause per-sample gain recomputation. No live CPU-budget test, convolution, tail-preserving mode transition or smoother room-size retiming yet.

Core tests cover static notch depth, fully wet all-pass magnitude, channel isolation, impulse onset, stereo diffusion, late tail decay at 44.1/48/96 kHz, decay/damping controls, mono-width projection and block partition independence for both modes. At 48 kHz the 1-second undamped impulse has total stereo energy 1.10813 in the first half-second, 2.15583e-6 in the 1–1.5 second window, and 2.18585e-12 after 2 seconds (3-second capture). With otherwise matched settings, 0.4-second and 3-second nominal decay give late energy (1–2 s) 1.6512e-15 and 0.0330387 respectively; damping 0.8 reduces the latter to 0.000511551. These are impulse-energy measurements, not listening-quality scores. Actual libobs stereo tests verify notch, all-pass response, nonzero reverb, bypass and Sound fixture modulation/fallback. Installed GUI and actual neural producers remain unqualified.
